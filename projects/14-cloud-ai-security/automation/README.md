# ⚠️ Solution: use only if stuck

flAWS and PortSwigger have their own built-in hints; use those for the challenges. This folder
holds the coding-exercise solutions.

| File | What it does |
|---|---|
| `python/iam_lint.py` | Flags risky patterns in AWS IAM policy JSON |
| `samples/policies/*.json` | Sample policies (one good, several risky) to lint |
| `python/llm_canary_test.py` | Measures canary-secret leakage from a local LLM (Ollama API) across test prompts, with an optional output filter |
| `python/prompts.txt` | Example test prompts for the harness |
