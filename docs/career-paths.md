# Career Paths: Find What You Like

You don't need to pick a specialty yet. Most people's first job is SOC, IT or general security,
and they specialize later. Use the projects to **test** each path: after each one, write a
line in your WORKLOG answering *"Would I want to do this 40 hours a week?"*

## The main paths

### SOC analyst / detection engineer (blue team)
- **Day to day:** triage SIEM alerts, investigate suspicious activity, escalate incidents, tune
  noisy detections, write new ones.
- **You'll like it if:** you enjoy puzzles, patterns in data, and "what actually happened here?"
- **Projects:** P02, **P08**, P10 (blue), P11
- **Certs (later):** Security+, CySA+, BTL1, SAL1
- **Entry point:** the most common first cyber job; many interns start here.

### Penetration tester / red team (offensive)
- **Day to day:** scoped attacks on networks, web apps and AD, then **writing the report**
  (roughly 40% of the job).
- **You'll like it if:** you love breaking things *and* can explain them clearly in writing.
- **Projects:** **P06**, **P07**, P10 (red), P09 (challenge design)
- **Certs (later):** PJPT/PNPT, eJPT, OSCP (the big one), BSCP for web
- **Reality check:** junior pentest roles are competitive; strong write-ups and reports set
  you apart.

### DFIR (digital forensics & incident response)
- **Day to day:** respond to breaches, collect and analyze memory/disk/logs, build timelines,
  write reports that may go to legal.
- **You'll like it if:** you're detail-obsessed and like detective work.
- **Projects:** **P11**, P08, P10
- **Certs (later):** BTL1, GCFE/GCFA (expensive; often employer-paid)

### Security engineer / infrastructure security
- **Day to day:** build and harden systems, firewalls, identity, VPNs, logging pipelines;
  automate everything.
- **You'll like it if:** you enjoyed building the lab more than attacking it.
- **Projects:** **P01**, P03, P04, P05, P07 (defend), P12, **P13**
- **Certs (later):** Security+, CCNA, vendor certs (Microsoft SC-series, Palo Alto)

### GRC (governance, risk & compliance)
- **Day to day:** policies, risk assessments, audits, mapping controls to frameworks (NIST CSF,
  800-53, ISO 27001, SOC 2), vendor risk.
- **You'll like it if:** you like the big picture, writing, and working with people across the
  business. Less hands-on-keyboard.
- **Projects:** **P12**, P03 (policy), P10 (AAR)
- **Certs (later):** Security+, ISC2 CC, CISA/CRISC (later in career)

### Cloud security / DevSecOps
- **Day to day:** secure AWS/Azure/GCP, IAM, infrastructure as code, CI/CD pipelines, container
  security.
- **You'll like it if:** you like coding and automation and want strong job demand.
- **Projects:** **P13**, **P14**, P12
- **Certs (later):** AWS Cloud Practitioner → AWS Security Specialty, AZ-500

### AI security (emerging)
- **Day to day:** test LLM apps for prompt injection and data leakage; secure ML pipelines.
- **Projects:** P14, P06 (web fundamentals still apply)
- **Note:** postings are rare but growing, and offensive teams are starting to ask about it.

## Certification strategy (student budget)

1. **Free first:** ISC2 Certified in Cybersecurity (CC) has periodically offered free exams for
   members (check current terms). Also look at Google/Microsoft student programs.
2. **Security+** if you have budget: it's the most-listed "preferred" cert. Use CompTIA's
   student discount.
3. Then specialize: pentest → PJPT/eJPT; SOC → CySA+ or BTL1; cloud → AWS.
4. Don't collect certs instead of building things. One cert plus this documented lab beats
   four certs and no projects.
